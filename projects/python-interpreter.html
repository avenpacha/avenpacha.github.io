Building a Python Interpreter

Developing and integrating the components of a custom interpreter through collaborative software development.

Our three-person team built a small interpreter in Python that reads written instructions and executes operations such as variable assignments, arithmetic calculations, and print statements.

My contribution: I developed the Abstract Syntax Tree (AST) nodes and parser, which organize written instructions into a structure the interpreter can evaluate.

Project Overview

For this group project, our team developed an interpreter for a small custom programming language. The program processes written instructions and executes operations such as variable assignments, arithmetic calculations, and print statements.

We divided the interpreter into interconnected components, with each team member responsible for a different part of the program. I developed the AST nodes and parser, which work together to recognize the structure of instructions and prepare them for execution.

Completing the project required us to understand how our individual components worked together, coordinate their integration, and test the complete program. I also contributed to our shared testing, documentation, and project demonstration.

My Role & Contributions

My primary responsibility was developing the Abstract Syntax Tree (AST) nodes and parser. These components transform the tokens produced by the lexer into a structured representation that the interpreter can use to execute the program.

AST Development

Defined the structures used to represent variable assignments, print statements, numeric values, variables, and arithmetic expressions.

This structure makes it possible for the interpreter to recognize different types of instructions and process them consistently.

Parser Development

Implemented the parsing logic for recognizing valid instructions, applying the language's grammar, and handling the correct order of arithmetic operations.

The parser organizes tokens into AST nodes that the interpreter can evaluate.

Integration & Testing

Collaborated with my teammates to bring our separately developed components together into a functioning interpreter.

Contributed to testing the complete program and documenting its functionality in our final report and demonstration.

How the Interpreter Works

Our interpreter processes written instructions through several connected components. Each component performs a different task before the program produces its final output.

1. Lexer

Reads the source code and breaks it into recognizable pieces called tokens.

Developed by a teammate

2. Parser & Abstract Syntax Tree

The parser checks how the tokens fit together according to the language's grammar. It then organizes them into an Abstract Syntax Tree (AST), which represents the instructions in a structured form.

This includes handling variable assignments, print statements, arithmetic expressions, and the correct order of operations.

My individual contribution

3. Interpreter

Evaluates the AST, executes the instructions, and produces the program's output.

Developed by a teammate

Example Program

The following example demonstrates how our interpreter processes variable assignments and arithmetic calculations. 

let x = 10 + 5;
let y = x * 2;
print(x);
print(y);

Output: 

15
30

The interpreter first assigns the value 15 to the variable x, then uses that value to calculate y. The print statements display the two results.
