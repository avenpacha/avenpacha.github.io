CS640 — Advanced Database Systems

Study Abroad Budget Calculator & Advising Platform

A full-stack web application that helps students estimate study abroad costs, compare program options, and prepare for advising conversations.

This application began as my group's final project for CS640 Advanced Database Systems. We developed a database-backed application using Python Flask and MySQL to manage study abroad program, student, and budget information.

After the course ended, I continued developing the project independently, expanding the original database application into a more complete student-planning and advising platform that I could deploy as part of my portfolio.

From CS640 Final Project to Portfolio Application

The original course project focused on applying relational database concepts through a practical web application. Our group connected a MySQL database to a Python Flask application and browser-based interface.

During the course project, I contributed to database and application development, SQL integration, testing, debugging, and troubleshooting how information moved between the application and database. I also presented the completed project to our professor and graduate Computer Science classmates.

After CS640, I continued developing the project independently with greater attention to student workflows, advising needs, user experience, and cloud deployment.

Key Features & Design Decisions

As I expanded the application, I focused on how database functionality could support real study abroad decisions while keeping complex information understandable for users.

These features illustrate how I approached the application from both a study abroad administration perspective and a human-computer interaction perspective.

Student Planning

Guided Student Questionnaire

Students are guided through the information needed for their study abroad planning rather than being presented with one large form.

From an advising perspective, this creates a more structured student profile and collects information that may be useful later when discussing program fit, preferences, and costs.

From a user-experience perspective, breaking the process into smaller steps reduces the amount of information users need to process at one time and gives them a clearer sense of progression.

Decision Support

Program Search & Comparison

Students can explore program options and compare multiple choices using a consistent set of information.

In study abroad advising, students may need to compare programs across different countries, academic terms, providers, institutions, and cost structures. Bringing that information together makes those differences easier to evaluate.

The interface is designed to support comparison rather than requiring users to remember information from several separate pages. This reduces cognitive load and supports more informed decision-making.

Financial Planning

Transparent Budget Estimates

The application organizes study abroad costs into understandable categories rather than presenting students with only one total.

This reflects an important part of study abroad planning: the advertised program price may not represent the student's full financial commitment. Housing, transportation, airfare, living expenses, and other costs can all affect affordability.

Showing how an estimate is constructed makes the result easier to understand and gives students more context for planning and advising conversations.

Study Abroad Administration

Advising Profiles

Student planning information can also be organized into an advising-oriented view.

From an administrative perspective, this creates continuity between what a student researches independently and what an advisor may need to review during a meeting.

From an HCI perspective, the same underlying database information is presented differently depending on the user's task. Students need guidance and comparison tools, while advisors need a concise view of the student's planning context.

Full-Stack Architecture

The application connects a browser-based interface to Flask application logic and a relational MySQL database.

Front End

HTML, CSS, and JavaScript provide the forms, navigation, filtering, comparison tools, and other interactive elements.

Application Layer

Python and Flask manage routes, application logic, validation, authentication, and communication with the database.

Database Layer

MySQL stores interconnected information about students, programs, costs, budgets, and advising-related data.

Working across these layers gave me experience connecting user-facing functionality with server-side logic and relational data rather than treating each part of the application as an isolated component.
