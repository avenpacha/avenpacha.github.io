CS591 — Advanced Artificial Intelligence

Machine Learning Optimization & Neural Network Classification

A team project exploring machine learning optimization from first principles and applying a TensorFlow neural network to a real-world image classification problem.

Team Project Python TensorFlow Machine Learning

Project Overview

This project was completed as part of a five-person team in CS591: Advanced Artificial Intelligence. The project combined machine learning fundamentals with a practical neural network application.

In the first part, the team implemented Gradient Descent and Stochastic Gradient Descent from scratch to fit polynomial curves to a dataset. In the second part, the team designed and trained a feed-forward neural network using TensorFlow/Keras to classify clothing images from the Fashion-MNIST dataset.

Part 1

Optimization from Scratch

The first part of the project focused on understanding how machine learning models update feature weights during training. The team implemented both Gradient Descent (GD) and Stochastic Gradient Descent (SGD) rather than relying on a pre-built optimizer.

The input data was normalized to prevent exploding gradients when working with higher-order polynomial features. Experiments compared models using three, four, and five features and learning rates of 0.01, 0.05, and 0.10.

GD vs. SGD

Compared the behavior of batch Gradient Descent with the faster but noisier updates produced by Stochastic Gradient Descent.

Model Complexity

Tested quadratic, cubic, and quartic polynomial models to examine how additional features affected curve fitting.

Learning Rates

Evaluated multiple learning rates to observe how step size influenced the speed and stability of model training.

Part 2

Fashion Image Classification

For the applied portion of the project, the team used the Fashion-MNIST dataset to explore computer vision and automated clothing classification.

The model was built using TensorFlow/Keras and used a flattened 28 × 28 pixel input, a hidden layer with 128 ReLU neurons, and a 10-class Softmax output layer. Stochastic Gradient Descent was used as the optimizer to connect the neural network application back to the optimization concepts explored earlier in the project.

60,000 Training Images

Results & Limitations

The neural network reached a test accuracy of 85.25%. Training and validation accuracy followed similar trends, suggesting that the model generalized reasonably well to unseen images.

One important limitation was the use of a Flatten layer. Converting each two-dimensional image into a one-dimensional array removes spatial relationships between nearby pixels. A future version could use a Convolutional Neural Network (CNN) to preserve and learn from spatial features such as edges, shapes, and textures.

What I Learned

This project strengthened my understanding of how optimization methods affect the way machine learning models learn. Working through Gradient Descent and Stochastic Gradient Descent helped make concepts such as feature weights, learning rates, and convergence more concrete. The neural network portion also gave me experience with the process of preparing data, building and training a model in TensorFlow, evaluating its performance, and considering the limitations of the selected architecture.
