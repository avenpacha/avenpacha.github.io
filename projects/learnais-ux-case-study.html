learnAIS: From UX Research to a Live Educational Website

Designing, testing, and developing an interactive educational website from initial concept to finished product.

I developed learnAIS as an individual academic project, working through user research, interface design, prototyping, usability testing, design revisions, and front-end implementation.

The result is a working educational website that introduces Artificial Immune Systems (AIS) and bio-inspired computing through structured lessons and an interactive demonstration.

Project Overview

learnAIS is an educational website introducing Artificial Immune Systems (AIS) and bio-inspired computing. I designed it primarily for Computer Science and IT students who are familiar with computational concepts but may have limited knowledge of biology.

My goal was to make a complex technical topic easier to explore through clear explanations, organized lessons, intuitive navigation, and an interactive demonstration.

Rather than beginning with the website's code, I worked through the UX design process to identify user needs, explore possible interfaces, create prototypes, and evaluate feedback. I then used those design decisions to develop the finished website.

My Role

UX research, user personas, wireframing, interface design, Canva prototyping, usability testing, design iteration, HTML/CSS/JavaScript development, and project documentation.

My UX Design Process

Each assignment in my Human-Computer Interaction course built on the previous one, allowing me to develop the website from an initial concept into a working product.

Understanding the Users

I began by considering the needs of students learning about bio-inspired algorithms. I also explored how users with different technical backgrounds might approach the website.

I developed three user personas and usage scenarios to identify different learning goals and navigation preferences.

This process informed an important design decision: the website needed to support both guided learning for beginners and direct access to individual topics for returning or more experienced users.

Design Goal

Make a complex technical topic approachable through a clear learning path while preserving the flexibility to explore individual sections.

Exploring Initial Design Concepts

Before creating a digital prototype, I sketched three low-fidelity interface concepts to explore different ways of organizing the website's content and navigation.

Selecting a Design Direction

I selected Interface Option 3 because it combined a structured, course-style learning sequence with links that allow users to navigate directly to individual sections.

This approach supports users who prefer to progress through the lessons in order while providing flexibility for those who want to explore specific topics independently.

Mid-Fidelity Prototyping & Design Iteration

I used Canva to develop interactive mid-fidelity prototypes before implementing the website in code. The initial prototype allowed me to test how users started the course, moved between lessons, and navigated directly to different sections.

Prototype A — Initial Design

In my initial prototype, users could select individual lessons from the homepage or click Start the Course, which took them directly to the first lesson, What Is AIS?

Prototype B — Revised Design

During usability testing, all four participants wanted a clearer understanding of how many lessons the course contained and where they were in the learning sequence.

In response, I added an About the Course page outlining the lessons and updated the Start the Course button to take users to that overview first.

I also changed the button to navy blue to make it more visually prominent as the main starting point.

Usability Testing & Feedback

I conducted usability testing with four participants using the initial mid-fidelity prototype. Participants followed a user manual to complete navigation tasks and then provided feedback through qualitative and quantitative evaluation forms.

All four participants reported completing the assigned tasks. They found the guided navigation helpful, particularly the Start the Course and Forward buttons.

However, all four participants also wanted a clearer indication of the course structure or their progress through the lessons. This recurring feedback helped me identify a specific opportunity to improve the experience.

What I Learned

Users could navigate the course, but they wanted a better understanding of what to expect before beginning.

What I Changed

I added an About the Course page and changed the Start the Course button to open that overview first.

Why I Chose This Approach

The new page provides an overview of the lesson sequence without adding a progress bar or unnecessary visual complexity.

I also made the About the Course page accessible from the navigation bar and footer. These revisions were incorporated into the finished website.

Testing Scope

The participant feedback came from testing the initial mid-fidelity prototype. The revised prototype and completed website were not separately evaluated with the same participants as part of this documented testing.

From Prototype to Working Website

After completing the design and evaluation stages, I implemented learnAIS using HTML, CSS, and JavaScript in Visual Studio Code.

I developed the website's individual lesson pages and navigation, translated the visual design into code, and created an interactive demonstration to support the educational experience.

HTML — Website Structure

Built the individual pages and organized educational content into a sequence of lessons with consistent navigation.

CSS — Interface Design

Implemented page layouts, typography, spacing, navigation, and consistent styling across the website.

JavaScript — Interactivity

Developed an interactive demonstration that allows users to adjust algorithm parameters and view dynamically updated explanations and output.

Reflection & Future Improvements

This project helped me connect UX/UI design with front-end development. I gained experience evaluating a design before coding, making decisions based on user feedback, and turning a revised prototype into a working educational website.

One of my most important takeaways was that users can navigate an interface successfully while still identifying ways to make the experience clearer. Their feedback about course progress led me to revise the navigation before completing the website.

In a future iteration, I would conduct additional usability testing with the completed website and continue refining its experience across different screen sizes.
