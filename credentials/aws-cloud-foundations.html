Credential Overview

As part of CS506: Distributed Cloud Computing, I completed the AWS Academy Cloud Foundations curriculum. The training introduced fundamental cloud computing concepts and provided practical experience with Amazon Web Services technologies and cloud architecture.

Successful completion of the training resulted in the AWS Academy Graduate – Cloud Foundations digital credential.

Key Learnings

One of my key learnings from this course was developing a stronger understanding of cloud computing and the different services available through AWS. Through AWS Academy Cloud Foundations, I learned about core cloud concepts as well as AWS services related to security, networking, compute, storage, databases, cloud architecture, and monitoring. The course helped me understand not only what these services do, but also how they can work together within a cloud environment.

Challenges & Growth

One of my biggest challenges was distinguishing between the many AWS services because several of them serve related purposes and have similar names. It was challenging at first to remember when one service would be more appropriate than another. I overcame this by completing AWS Academy labs, knowledge checks, and course activities and repeatedly reviewing the purpose and use cases of each service. Over time, the hands-on practice helped me become more comfortable recognizing the differences between AWS services and understanding how they fit into a larger cloud architecture.
